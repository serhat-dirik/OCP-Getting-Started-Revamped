= version-anchor-guard canary

Fixture for `tools/lint/version-anchor-guard.py --self-test`. Every detector must fire here, and
the opt-out must suppress — and must STOP suppressing at the next blank line. If a run over this
file comes back clean, the GUARD is broken.

NOT a real page — it is never built (it lives under tools/, outside the Antora content root).

Every line below carries its own expectation as a trailing marker: the positive one means the guard
has to flag that line, the negative one means it has to stay silent. (Neither is spelled out in this
paragraph, because the self-test scans the whole file for them.) The self-test compares the flagged
line numbers against those markers. That is stronger than counting offenders or collecting detector
kinds: it was a kinds-only assertion that let the opt-out be blinded with the self-test still
passing, because the extra offenders that appeared were of kinds already seen elsewhere.
