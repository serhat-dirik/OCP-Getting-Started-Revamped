# module-block-guard fixtures

One miniature tree per detector, each tripping EXACTLY ONE. Several want to trip two — an
interleaved catalogue also mismatches the nav headings, and a row moved out of its wrapper also
leaves its owner holding two rows — so the fixtures below deliberately hold the other variable
still. A fixture that tripped two detectors would leave both readable as proven while either
could silently stop working.

`canary-empty` carries only a modules.yaml: no nav and no index, so the scope floor is the only
thing left to fire.
