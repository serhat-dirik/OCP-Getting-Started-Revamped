// A definition OUTSIDE every guard renders in both flavors — the shape the fix produces, and the
// one a guard must never flag. The `ifndef::demo[…]` line beside it is the INLINE conditional form:
// it opens no region, and the preprocessor keeps or drops the one line. It is here so the inline
// form has a witness of its own — read as a region opener it would swallow the rest of the file,
// and read as ordinary text it would leak a lab-only definition into the demo projection.
[source,sh]
----
export SHARED_NS="$(oc whoami)-dev"
ifndef::demo[INLINE_NS=lab-only-value]
----
