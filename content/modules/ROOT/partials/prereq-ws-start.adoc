[NOTE]
.Before you start — confirm your environment
====
This module is self-contained: you do *not* need to have completed any earlier module.

*If you started the setup on the previous page* — check the *Terminal* tab. If it says
`{module-id} is ready — start the lab.`, you are good to go.

*If you did not, or you came straight here* — run this now from the *Terminal* tab and give it a few
minutes:

[source,sh,role=execute,subs="attributes"]
----
ws prep {module-id}
----

It checks your project, tells you if anything is left over from a previous module, and *asks before
wiping* anything to set up this module's world. Safe to run at any time — if your environment is
already prepared it says so and changes nothing.

Only if `ws prep` itself reports a platform error, tell your instructor.
====
