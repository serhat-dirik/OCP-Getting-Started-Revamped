[TIP]
.Start your environment now — it builds while you read
====
This module's lab needs its own environment, and setting it up takes a few minutes.
Kick it off *now*, from the *Terminal* tab, and it will be ready by the time you finish this page:

[source,sh,role=execute,subs="attributes"]
----
ws prep {module-id}
----

You do not have to wait for it. Come back to this page and keep reading — the terminal will tell you
when it is done, and the lab page starts by confirming it.

It is safe to run at any time: it checks what is already in your project, tells you if anything is
left over from an earlier module, and *asks before wiping* anything.
====
