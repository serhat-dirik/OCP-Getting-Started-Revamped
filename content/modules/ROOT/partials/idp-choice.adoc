// The cluster has ONE sign-in provider, a Keycloak realm (owner decision 2026-11-12), so OpenShift
// never shows a choice of sign-in methods: every tool lands on the same Keycloak form, and one sign-in
// covers the session. Say what the attendee sees; never name the provider (`rhbk` on RHDP, `ogsr-sso`
// where the install brings its own) — that is a property of the cluster, not of the workshop.
[NOTE]
====
*Signing in to a platform tool?* Enter your workshop username (`{user}`) and the workshop password on the sign-in page.
You sign in once: the other tools that use OpenShift sign-in open without asking again.

*Developer Hub* uses the same sign-in: its page offers one option, and *Sign In* opens it as you.
*Gitea* has its own front door and asks for a username and password in its own form.
====
